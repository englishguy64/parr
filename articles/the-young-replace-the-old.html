The Young Replace The Old

24 November 2026

As I continue to develop this web site using Claude and Codex I am having some strange sensations.

There is a relief that the coding and debugging grind is over. Happiness that I can now build and learn things at speed that was not even possible in my best coding days.

Watching YouTube there are many developers in an identity crisis. I have been writing code too long and it was never really that important to me. It was always about delivery. For them it was the coding and the challenge, for me it is the creation and delivery. The truth is for every one of those lost souls there are thousands pushing ahead and adapting to be relevant. Those developers that cannot handle the change will be forgotten. The young replace the old.

Ever since I started coding in 1980 the industry was always evolving, technologies became outdated and so did my skills, with each new revolution networking, internet, cloud and now AI came a pressure to learn and adapt. The young coming out of Universities were already up to date and it was 'my generation' that had to keep up.
