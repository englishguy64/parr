About Azure API Management (APIM)

Azure API Management or Azure APIM as it sometimes referred to. This is Microsoft Azure defined resource which allows organisations to manage their API estates. Documentation is available from your Microsoft Azure portal.

APIM Workspaces

An API Estate can be divided into workspaces. Each workspace can be managed in isolation. Each workspace can access shared API assets but not directly from another workspace.

APIM Authentication (Who can do what!)

Azure RBAC built-in roles (management plane)
- API Management Service Contributor: Full management of the service, its APIs, policies, products and users.
- API Management Service Operator Role: Manage the service but not its APIs or policies.
- API Management Service Reader Role: Read-only access to the service and its entities.
- API Management Service Workspace API Developer / Product Manager / API Developer / Reader roles: the same idea, scoped to a workspace.
- API Management Developer Portal Content Editor:Edit developer portal content.
- Owner, Contributor, Reader: The generic Azure roles also apply at the subscription, resource group or service scope.

Built-in APIM groups (APIM Developer Portal and Azure Subscriptions)
- Administrators:The Service Administrators.
- Developers: Portal Users who can sign up for Products and get Subscription Keys.
- Guests: Unauthenticated or Limited visitors who can browse products but not subscribe.
