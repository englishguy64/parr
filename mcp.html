Prompt Engineering - A New Way of Working

Many people now use prompts for personal and work tasks, and they are getting better at it. Workforces have started building catalogues of skills and agents that automate the most frequent prompts.

Prompts are written in AI chatbots, which can also be embedded in applications. Two popular examples are Anthropic's Claude and OpenAI's ChatGPT. This article uses the Claude Code desktop app for simplicity.

Chatbots reduce the need to learn, use and develop complex UIs. Information workers who cannot prompt well are likely to be at a disadvantage in the future job market.

Why Do AI Chatbots need MCP?

MCP lets chatbots talk to third-party applications. Without it, or specialised model training, they would not know how to access their functionality or bypass their UIs. MCP connectors and servers provide that knowledge.

MCP connectors have two parts, an MCP client (included in Claude Code) and an MCP server, which the client calls to discover and use its capabilities.

MCP is an evolving technical standard developed at modelcontextprotocol.io.

How to Connect Using MCP?

Your application may already do it for you. If you are using a popular AI chatbot such as Claude Code, just ask for information on how to connect an MCP connector.

The number of MCP servers that can be connected may depend on a subscription level, so ask the subscription owner or your chatbot, if you are unsure. At the time of writing, free tier subscriptions are limited.

Please note that some connectors require authentication (login) to gain authorisation (what can be done), but chatbots usually handle this for you.

MCP Server Tools and Capabilities

An MCP server has predefined tools that decide what can be done in the third-party application. AI chatbots discover these tools through the MCP client, which is usually built in.

The application may have functionality in its own UI that is unavailable through MCP server tools, either deliberately or because the MCP server is not yet rich enough. Ask your AI chatbot to summarise what is possible to avoid disappointment. For example, you may find you can read data but not update it.

As AI matures, MCP servers will become richer, more powerful and more important, driven by custom demand and feedback. Most software is likely to offer an MCP server.

Creating Your Own MCP Solution

You can develop your own MCP connector or solution if you need to.

You may need to authenticate and study the underlying software APIs the tools will use. Some APIs are metered on a pay-as-you-go basis, so research before you begin to avoid nasty surprises. There are plenty of internet resources to help, including Claude.

Your MCP solutions can be hosted wherever you want, as long as your intended audience can reach them. This is an infrastructure question rather than a limitation.

MCP Gateways

Gateways provide a single entry point for multiple MCP servers and let you self-host your own. If you are interested, ask your AI chatbot for more information.
